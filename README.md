# zenit-sirene-2

Sirène Links — página de links da Sirène Vicente Machado (mar vermelho com abridores e sereia) + jogo Proteja a Sereia.

Site estático de um arquivo só (`index.html`), sem dependências nem build. Publicado pelo GitHub Pages a partir da branch `main`.

- Links: avaliação no Google, cardápio e Instagram (@sirene_vicente).
- Jogo: o ranking fica salvo no próprio aparelho do jogador; para um ranking único entre todos é preciso um backend (ex.: Supabase).
